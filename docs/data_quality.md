측정일 2026-11-03. 모든 수치는 `backend/scripts/audit_data_quality.py`가 Supabase를 읽기 전용(`SET TRANSACTION READ ONLY`)으로 조회한 결과이고, 리뷰 제목·본문·작성자는 출력하거나 이 문서에 옮기지 않았다. OpenAI는 부르지 않았다. 확인하지 못한 것은 "미확인"으로 적었다.

## 3. 대표성과 표본

| 지표 | 값 | 95% 윌슨 구간 |
| --- | --- | --- |
| 회차 밖 리뷰 | 1,063 / 1,302 = 81.6% | 79.4% ~ 83.7% |
| 제목·본문 모두 없음 | 992 / 1,302 = 76.2% | 73.8% ~ 78.4% |
| 5점 | 1,164 / 1,302 = 89.4% | 87.6% ~ 91.0% |
| 1점 중 제목·본문 없음 | 8 / 18 = 44.4% | 24.6% ~ 66.3% |
| 2026-Q1 제품군 1의 제목 또는 본문이 있는 글 | 13 / 63 = 20.6% | 12.5% ~ 32.2% |
| 2026-Q1 제품군 2의 제목 또는 본문이 있는 글 | 6 / 37 = 16.2% | 7.7% ~ 31.1% |
| 2026-Q2 제품군 1의 제목 또는 본문이 있는 글 | 14 / 78 = 17.9% | 11.0% ~ 27.9% |
| 2026-Q2 제품군 2의 제목 또는 본문이 있는 글 | 14 / 61 = 23.0% | 14.2% ~ 34.9% |

계산식(계산): k는 해당 건수, n은 전체 건수, p = k / n, z = 1.96일 때
중심 = (p + z² / 2n) / (1 + z² / n), 반폭 = z · √(p(1 − p) / n + z² / 4n²) / (1 + z² / n), 구간 = 중심 ± 반폭. 각 행의 k와 n은 표에 적은 값이다.

해석할 때 주의할 점:

- 이 구간은 적재된 리뷰가 어떤 모집단에서 임의로 뽑힌 표본이라고 가정한 계산이다. 수집 범위를 모르므로(5절) 그 가정이 맞는지는 미확인이다.
- 회차별 제목 또는 본문이 있는 글은 6~14건이다. 구간이 넓고(예: 제품군 2의 2026-Q1은 7.7% ~ 31.1%), 제품군 2의 두 회차 구간은 서로 겹친다.
- 5점이 89.4%라서 1~4점 구간의 건수는 작다(1점 18건, 2점 4건).
- 광고성 판정 표본이 작다는 점과 임계값이 근거 없는 가정이라는 점은 `README.md`의 한계에 있다.

## 4. 합성 설문 구조

(출처: `backend/app/services/synthetic_survey.py`, `docs/plan.md`의 Phase 0c 기록. 모든 수치는 합성이고 성과로 쓰지 않는다.)

- **문항별 독립 추출**: 응답은 문항마다 고정 확률표에서 따로 뽑는다. 문항 사이에 상관 구조가 없다. 시드는 고정 상수(20261103)다.
- **의도적으로 다른 3문항**: 두 회차의 확률표가 다른 문항은 q01(전반 만족도), q07(가장 불편했던 점), q09(지인 추천 경험)뿐이고 나머지는 같다. 코드 주석은 q01을 "만족 쪽으로 이동", q07을 "현상·인화 대기 비중 증가", q09를 "추천 경험 '예' 증가"로 적었다.
- **제품군 공통**: 설문 응답에는 `family_id`가 없다. 제품군 1·2의 설문 수치가 같은 것은 이 구조 때문이다.
- **확률표 대비 생성 빈도(실측, 합성)**: 두 회차 × 문항 × 보기 94칸을 확률표(q08은 코드의 추출 규칙에서 계산한 주변 확률)와 DB 빈도로 비교했다.
  - 최대 절대 차이 12.0%p, 평균 절대 차이 2.86%p.
  - 가장 큰 차이 3칸:

    | 회차 | 문항·보기 | 확률표 | DB | 차이 |
    | --- | --- | --- | --- | --- |
    | 2026-Q1 | q08 보기 2 | 37.0% | 25.0% | 12.0%p |
    | 2026-Q1 | q07 보기 5 | 28.0% | 40.0% | 12.0%p |
    | 2026-Q2 | q10 보기 2 | 30.0% | 22.0% | 8.0%p |

  - 참고(계산): 응답 100건에서 확률 0.3인 칸의 이항 표준오차는 √(0.3 × 0.7 / 100) ≈ 4.6%p다.
- **확률표를 가설 규칙(R2, R3)에 맞춰 조정했다는 근거: 근거 없음.** `synthetic_survey.py`, `hypotheses.py`, `docs/`를 검색했을 때 확률표와 R2·R3을 연결하는 문장이 없다. 있는 것은 `synthetic_survey.py:3-5`와 `docs/plan.md`(Phase 0c의 "합성 데이터의 성격" 항목)의 "실제 리뷰나 판정 통계에서 가져오거나 맞추지 않았다"는 문장, `synthetic_survey.py:58`과 같은 plan.md 항목의 "두 회차에서 의도적으로 다른 문항은 3개뿐"이라는 문장이다. 조정했다는 문장도, 조정하지 않았다는 문장도 없다.
  - 관찰(계산, 의도 여부는 근거 없음): `docs/spec.md`의 R3 조건(q01의 4·5점 합 60% 이상이고 q09 "아니오" 50% 이상, 임계값은 가정)에 확률표 값을 대면 2026-Q1은 두 조건을 모두 채운다(0.40 + 0.26 = 0.66, 0.55). 2026-Q2는 "아니오"가 0.45라서 채우지 못한다.
- **회차 간 변화는 추세 근거로 쓸 수 없다.** 변화는 확률표에 사람이 넣은 값이고 실제 응답에서 관찰한 것이 아니다. 표본 크기(100건)에서 생기는 무작위 차이도 위 비교처럼 최대 12%p까지 나왔다.

## 7. 한계

- 현재 분석 데이터는 쿠팡의 후지필름 리뷰 CSV이고, 운영 시나리오(6절)의 데이터는 공식 이커머스의 후기와 설문이다. 두 출처가 같은 성격인지(작성 환경, 평점 분포, 본문 비율, 후기 작성 시점의 분포)는 검증하지 않았다. 6절의 건수 표는 쿠팡 데이터의 건수이므로 공식 이커머스에 그대로 옮길 수 없다.
- 수집 방식·시점·범위가 미확인이라(5절) 3절의 신뢰구간이 전제하는 임의 표본 가정과 회차 밖 81.6%의 원인(수집 범위 때문인지, 리뷰 작성 시점 분포 때문인지)을 판단할 수 없다.
- 설문은 합성이고 제품군 구분이 없다(4절). 설문 쪽 결과로 제품군을 비교하거나 회차 간 추세를 말할 수 없다.
- 제목·본문이 모두 없는 글 76.2%는 평점만 있는 글이라 광고성 판정과 내용 분석이 불가능하다. 이 글들의 중복 여부도 판단할 수 없다.
- CSV 원본과 DB의 일치(적재 정확성)는 이번 점검에서 확인하지 않았다.
- 월 단위 집계는 구현되어 있지 않다. 6절은 사용자 제안이며 구현·검증이 없다.

## 8. 재현 방법

backend 폴더에서 PowerShell로 실행한다. `backend/.env`의 `DATABASE_URL`이 필요하고, DB는 읽기만 한다(`SET TRANSACTION READ ONLY`).

```powershell
.venv\Scripts\python.exe scripts/audit_data_quality.py
```

출력은 건수와 ID뿐이다. 이 문서의 수치는 2026-11-03 실행 결과이고, 데이터나 설문을 다시 적재하면 달라질 수 있다.
